# EmotionalAI Lab — Emotional v0.1.1

**Первый публичный выпуск проекта.** Emotional — автономный русскоязычный агент с локальной памятью, моделируемым эмоциональным состоянием, ассоциативным обучением и импортом знаний из Wikipedia. Для обычного диалога не нужны Ollama, Qwen, ChatGPT API или другой ИИ-агент.

## Запуск в Windows

1. Распакуй архив в отдельную папку.
2. Установи Python 3.10 или новее с Tkinter (обычный Windows-установщик Python подходит).
3. Дважды нажми `run.bat`.
4. Пиши в поле внизу окна Emotional.

Для консольного запуска используй `run_console.bat` или выполни `python main.py`. Python-пакеты сверх стандартной библиотеки не требуются.

## Что она умеет

- Сохранять каждый ход диалога (сообщение пользователя и ответ Emotional) в локальную базу SQLite.
- Выделять простые факты и предпочтения из обычных фраз, сохранять заметки и ассоциации между словами.
- Использовать прошлые сообщения при похожих вопросах. Команда `Правильно: ...` может записать исправление ответа; при повторении похожего запроса агент попробует использовать это исправление.
- Обрабатывать `Запомни: ...` и `Забудь ...`. Команды `/память`, `/история`, `/состояние`, `/цели`, `/ядро`, `/база` позволяют посмотреть состояние данных.
- Изменять моделируемые эмоции от событий диалога. Эти состояния влияют на тон некоторых разговорных ответов и сохраняются между запусками. Это программная модель поведения, а не доказательство сознания.
- Отвечать на поддерживаемые темы из встроенной базы, выполнять простые вычисления, давать примеры кода, переводить ограниченный набор распространённых запросов и создавать короткие творческие тексты.

## Wikipedia и интернет-знания

В окне **«Данные из интернета»** можно искать и загружать статьи русской или английской Wikipedia. Текст, адрес страницы, источник и сведения о лицензии сохраняются локально в `data/internet_knowledge.sqlite3`. После загрузки поиск по статьям работает без интернета.

После импорта можно нажать **«Обучить на загруженных статьях»**. Emotional обновит статистические ассоциации между понятиями из новых статей; источники отмечаются, чтобы повторное обучение не усиливало те же пары бесконечно. Это лёгкое ассоциативное обучение, не изменение весов нейросети.

В той же вкладке можно включить прямой онлайн-поиск Wikipedia для вопросов, на которые не хватает локальных данных, и запрос погоды. При выключенной опции диалог не обращается к интернету автоматически. Личные сообщения не отправляются в Wikipedia-поиск: в онлайн-функциях есть фильтр на персональные вопросы.

Wikipedia предоставляет содержимое на условиях CC BY-SA и/или GNU FDL в зависимости от страницы. Если распространяешь скачанные статьи отдельно от Emotional, соблюдай лицензию и указывай источник.

## Как работает память и обучение

- Эпизоды хранят полные реплики диалога и состояния Emotional в момент ответа.
- Заметки позволяют найти старую фразу по смысловому сходству; ассоциации расширяют запрос связанными словами.
- Автоизвлечение фактов работает для ряда простых конструкций («я люблю…», «мне нравится…», «мой любимый цвет — …»). Извлечённые факты могут уточняться явной командой `Правильно: ...`.
- Обычные сообщения обучают ассоциативные связи; стартовый корпус загружается один раз по контрольной сумме. Ассоциации помогают поиску, но не создают универсальное понимание языка.
- `python train.py --corpus data/seed_corpus.txt` обучает ассоциации на локальном текстовом файле.

## Файлы данных

- `data/agent_memory.sqlite3` — история, факты, заметки, эмоциональные снимки и ассоциации.
- `data/internet_knowledge.sqlite3` — скачанные статьи Wikipedia и импортированные документы.
- `persona.json` — имя, характер, тон и подробность ответов.
- `config.json` — пользовательские настройки. Свежая установка создаёт настройки из `config.template.json`.

Личные базы и пользовательские настройки не включены в ZIP. При обновлении распакуй программу поверх старой папки, не удаляя `data`, `persona.json` и `config.json`. Сделай резервную копию, если там есть важная история. Для полной очистки можно закрыть программу и удалить только те файлы данных, которые хочешь сбросить.

## Ограничения

Emotional — самостоятельный символьный/знание-ориентированный агент, не большая языковая модель. Она может отвечать полезно в поддерживаемых ситуациях, но хуже справляется с произвольными новыми вопросами. Память хранит опыт; ассоциативное обучение обновляет связи; это не то же самое, что обучение параметров трансформера. Не стоит хранить в приложении секреты, пароли или информацию, которую не хочешь записывать на этот компьютер.
