# Internet data sources and reuse notes

## Wikipedia

The optional importer uses Wikimedia's MediaWiki API to save article extracts locally. Texts are attributed with their article title and URL in the local SQLite database. Wikipedia text is generally available under Creative Commons Attribution-ShareAlike 4.0 and/or GNU Free Documentation License, subject to the article's own attribution details. Check the article page and Wikimedia licensing guidance before redistributing imported material.

The standalone agent does not download an instruction-response dataset and does not claim to fine-tune a neural language model. User-provided documents remain the user's responsibility; only import material you have permission to use.
