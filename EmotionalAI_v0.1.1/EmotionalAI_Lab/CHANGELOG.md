# CHANGELOG — EmotionalAI Lab

## v0.1.1 — первый выпуск

- Самостоятельное русскоязычное ядро Emotional: без обязательного внешнего ИИ, облачного API или стороннего сервера.
- Моделируемое эмоциональное состояние сохраняется между сообщениями; настроение влияет на стиль реакции в разговорных репликах.
- Долговременная SQLite-память записывает диалоги, ответы, заметки, извлечённые факты и ассоциации. Повторяющиеся сообщения не бесконечно дублируются как заметки.
- Явные команды `Запомни:`, `Правильно:` и `Забудь ...` изменяют локальную память; явные исправления сохраняются как примеры для будущих похожих запросов.
- Стартовый корпус усваивается один раз по контрольной сумме, чтобы обновление не дублировало начальные ассоциации.
- Статьи Wikipedia можно загружать в локальный корпус с сохранением заголовков, ссылок и лицензий; добавлена отдельная кнопка обучения ассоциациям на импортированных статьях.
- Поиск по загруженным статьям работает локально; прямой онлайн-запрос Wikipedia для неизвестных вопросов можно отдельно включить в настройках.
- Добавлены инструменты: арифметика, примеры кода, ограниченный перевод, короткие творческие запросы, локальный поиск и обработка контекста.
- Добавлены регрессионные тесты для реальных диалогов, памяти, эмоций и импорта знаний.

Обучение ассоциациям не является обучением весов большой нейросети и не гарантирует человеческого уровня понимания.
